The Motorola 68000 series is a family of big-endian CISC microprocessors first introduced in 1979 with the launch of the Motorola 68000[^1]:

## Family Members

### First Generation

- 68000
- 68EC000
- 68SEC000
- 68HC000
- 68008
- 68010
- 68012

### Second Generation (internally fully 32-bit)

- 68020
- 68EC020
- 68030
- 68EC030

### Third Generation (pipelined)

- 68040
- 68EC040
- 68LC040

### Fourth Generation (superscalar)

- 68060
- 68EC060
- 68LC060

### Others

- Freescale 683XX (CPU32 aka 68330, 68360 aka QUICC)
- Freescale ColdFire
- Freescale DragonBall
- Philips 68070
- APOLLO CORE 68080
